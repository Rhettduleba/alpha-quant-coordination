- **May 21, 2026** — Fix + finding (observation period) — Journal double-counting bug fixed, and a deeper data-source problem surfaced. **The bug:** `load_all_journal_rows()` (in `ai-trading-strategy-agent/src/advisor/trade_pattern_analyzer.py` — shared by `tradestation-bot/backtest.py` AND the live advisor's `learned_patterns.json` builder) globbed **every** `trade_journal*.csv` file. Those 56 machine-suffixed files are overlapping per-machine rotation snapshots of the same journal, so every trade was multiply-counted ~27×: 34,346 rows / 30,613 closed pairs instead of the true 1,342 / 1,143. **Fix (commit `675dcf5`, `alpha-quant` repo):** de-duplicate each relevant row on its full content before FIFO matching. **Cache regenerated:** the live `learned_patterns.json` was 9 days stale (May 12) AND corrupt — 25,526 trades / +$1,070,415 P&L, with impossible artifacts (32h avg holds, a 481-win/0-loss "setup") that the advisor was citing into control files (the May 21 control file's "MSFT −$84,211 all-time" is verbatim from it). Corrupt file backed up to `learned_patterns.CORRUPT-pre-dedup-fix-2026-05-21.json.bak`; regenerated with the fixed loader → 1,143 trades / +$25,925. **Deeper finding — the corrected numbers still do not match broker truth:** deduped journal = 1,143 pairs / **+$25,925 net**; V5 broker truth = 593 pairs / **−$2,282**. Root cause verified: the journal records order *submissions* at *limit prices* (1,271 of 1,342 rows are status `HTTP 200` = submission accepted; only 35 say `FILLED`; 1 is a rejected `HTTP 400` that is still counted as a trade). Journal-based backtesting/pattern-learning is therefore structurally `LOCAL_RECONSTRUCTION` — it assumes every submitted order filled at its limit and counts unfilled/rejected orders as real trades, overstating win rate and flipping P&L positive. **Implication:** trustworthy backtesting must be sourced from broker truth (`historicalorders` / `daily_reconciliation.py`), not the journal — the dedup fix is necessary but not sufficient. The advisor has been learning patterns from this distorted journal data.
